# Nebula reference library (Well Dipper)

Purpose: real photographs to guide the procedural 3D nebula renderer away from "it looks like a ring / a circle". Every image here shows some way real nebulae are NOT round: ragged outlines, one-sided glowing bowls carved into dark clouds, bright rims, pillars, filaments, dark lanes, layered depth. Category 4 is the deliberate exception (real bubbles), kept as a contrast.

How the files were obtained: every file was found on Wikimedia Commons, its licence/author read from the file page's `extmetadata` via the Commons API (2026-10-03), and the Commons 1600 px thumbnail downloaded and re-saved as JPEG (long side <= 1600 px). Nothing was cropped or colour-adjusted.

Licences allowed: public domain, CC0, CC BY, CC BY-SA (including ESA's CC BY-SA 3.0 IGO). No NC / all-rights-reserved files are included.

Distances and sizes are approximate, rounded values from the file descriptions or general literature; treat them as order-of-magnitude guides, not verified per row.

Scale key: **whole** = the whole object as a patch of sky; **region** = a large part of it; **detail** = a close-up feature.

Colour warning: most professional images are narrowband or infrared "representative colour" (e.g. JWST, Spitzer, Herschel, Hubble palette). They are references for SHAPE and STRUCTURE, not for what the eye would see. See category 8 and the link-only section for colour.
