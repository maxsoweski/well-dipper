## 0. Setup — three steps, once

**1. Start the game yourself** (I don't start servers — the sandbox reaps them):

```
cd ~/projects/well-dipper && npm run dev
```

**2. Turn the flag ON.** In the browser console, then let it reload:

```js
localStorage.setItem('wd.labGasBodies', '1'); location.reload();
```

**3. Travel to a body.** In the console:

```js
window._lab.spawnProceduralSystem('lab-procedural-88')
```

⚠ **The A/B is a reload, not a key.** There is no runtime toggle — `setLabGasBodiesOverride` exists
but is not exposed on `window._lab`, and the flag is deliberately `localStorage`-backed so it
survives a reload. So the honest comparison is: look ON, then
`localStorage.setItem('wd.labGasBodies','0'); location.reload();`, respawn the **same seed**, look
again. ⭐ This is worse than the bare-key A/B that has actually worked for you before. If the
reload cycle makes it hard to judge, say so and I'll expose a runtime toggle as its own small unit
— it needs care, because `window._lab` sits above `main.js`'s densest citation block.

- ⭐⭐ **F37 aurorae contribute NOTHING on any moon. Not one.** `condition.atmosphere` is null on
  **632 of 632** plain moons and `labCore.js:1045` multiplies by `hasAtmo`, so the aurora term is
  identically zero on every moon in the game. It was wired anyway, because the ledger row closes by
  *forwarding four values* and the zero is a world-generation fact rather than a wiring failure.
  **If the moons look identical in the aurora respect, that is expected and is not the thing you
  are judging.** This is written here because last time the moon UAT produced *"these are all
  identical"* on exactly this population.
- **The moon differentiation you SHOULD see** comes from F9/F10 chaos, F17 glacial landforms, F22
  polar caps, F23 snowline/frost, and B2's earlier frequency work — not from aurorae.
- ⛔ **Do not judge any of this on Sol.** Sol renders 18 NASA photographs through a different
  renderer with no world-engine condition fields, and is excluded in code. It is the one system
  that cannot test procedural generation.
- **B4 moves pixels by design.** Lighting changes what things look like; its Instrument C gate is
  deliberately *not* byte-identical. B3's is byte-identical and measured **zero delta**.
