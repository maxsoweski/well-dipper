**PARTIAL by subtype:** computed-but-not-rendered 6 · masked-only 7 · one-directional 3 · weak 4.

**Systemic read.** The *surface/relief* and *fluvial+gradational* spines are the most coherent regions of the system: the accumulated-h/grad combiner chain plus the `hostGrad = gradIn - gradBase` trick give mass-wasting, lava burial, dust mantling, fluvial incision, ejecta-on-craters, deltas-at-mouths, and orographic frost real, evidence-backed couplings. The *bands/storms* spine is also solid — jets, great spot, storm trains, and polar vortex all ride the shared band ladder.

The weakness is everything that needs a **second signal the forward combiner pass discards or never builds**:

1. **Per-basin pour-point fill is computed then thrown away** → every elevated-lake / closed-basin coupling fails (crater lakes, tarn lakes, karst cenotes, outflow source basins).
2. **Clouds occlude nothing** — the deck is an additive paint layer, never read as a medium (glint, terminator, city lights, limb all shine through).
3. **Weather/circulation × surface has no feedback path** — no superrotation cloud-clearing, no storm-genesis banding, no dust loft/redeposit.
4. **Cross-feature crustal partition is absent** — tessera/plateau, canyon/scarp, hex/shatter, chaos/cryoRidge run as independent province fields that never read each other.

Confidence is high wherever the audit cites a specific shader line that actually runs (most WIRED/PARTIAL). It is lower for a few preset-gating reconciliations (carbon × lava) and for resolution-capped effects that "run but don't show" at the 40k orbital mesh.

## Recurring Structural Causes (the architecture story)

These matter more than any single gap — they show where the **architecture**, not just wiring, is missing.

1. **Computed-but-not-rendered (highest leverage).** `priorityFlood()` already returns per-basin pour-point `filled` levels; the carve cube bakes only depth/mouth/order and the only standing-water term is the global `smoothstep(uSeaLevel±0.02, h)` (L435). **One discarded signal causes seven gaps.** Surfacing it is a wiring fix, not architecture.
2. **Clouds occlude nothing.** The F31 deck is added at the final composite (L1345) and never read as an occluder — four ABSENT edges, all closeable with a one-line `(1-cloudCoverage)` multiply on a signal already in scope.
3. **Weather/circulation × surface is architecturally missing.** Transient atmosphere and persistent surface never exchange material because the forward pass has no writable feedback buffer (dust loft, hotspot cloud-clearing, storm-genesis banding).
4. **One-directional via shared accumulated-grad.** `hostGrad = gradIn - gradBase` makes mass-wasting read every upstream host robustly, but the router samples height **once** and never re-routes — so landslide dams, sediment fill, and basin gouging cannot feed back.
5. **Cross-feature partition absent.** Features that should *divide* a surface run as independent province/noise fields that never read each other (canyons/scarps, plateaus/scarps, tessera/plateaus, chaos/cryoRidge, hex/shatter, dust/dunes).
6. **Masked-only where richer modulation is owed.** `(1-liquidMask)` correctly gates presence but stops at binary — no sea-ice rind, no shoreline sediment, no relief embayment (lakes×frost, machine×craters, magma×edifices).
7. **Shared-driver recomputation masquerading as coupling.** glacial×frost and sublimation×frost recompute the identical cold-cap field rather than reading each other's buffer — co-located but no true volatile-budget exchange.
8. **Manifest under-declares honored couplings.** Several real shader couplings (dust×craters, clouds×lightning, weatherBands×clouds, daysideThermal×nightsideThermal) are NOT in `ASSOCIATIONS.dependsOn` yet run at render time. The manifest has drifted below the shader; `dependsOn` is no longer a reliable single source of truth.
9. **Resolution/view-dependence ceiling.** A few couplings run but cannot show at the 40k orbital mesh (gorge depth, dune orientation, U-trough carving) — correctly deferred to a rich tier.

## Remediation Order

- **Phase 1 — One fix, seven gaps (keystone):** surface `filled` as a carve-cube channel / per-basin fill texture → `max()` into liquidMask. Closes craters×rivers, craters×lakes, rivers×lakes, lakes×deltas, karst×lakes; unblocks glacial×lakes, outflow×lakes.
- **Phase 2 — Wire-now batch (single-line, broad):** cloud occlusion (×sunglint/cityLights/terminator/limb); lava×frost, bioMats×frost, lakes×bioMats, lakes×dunes, hexTess×shatter, weatherBands×dustStorm, jets×greatSpot, lightning×dustStorm.
- **Phase 3 — Resolve-pass / re-order:** lava×mountains ponding, machine×craters & magma×edifices relief suppression, edifices×craters flank resurfacing, plateaus×canyons, karst×rivers router injection, glacial negative-carve, outflow head anchoring, shared volatile-budget for glacial/sublimation×frost.
- **Phase 4 — Needs-architecture (charter items):** river/mass-wasting re-route feedback; lava-as-fluid routing; weather×surface feedback; cross-feature partition generator; chaos shallow-liquid class; carbon hot variant; ecumenopolis continuum merge.
- **Phase 5 — View-dependent rich tier (hold):** glacial carving, dune orientation/echo dunes, gorge depth at close range.
- **Cross-cutting (once):** re-derive `dependsOn` from the shader so the manifest stops under-declaring.

Two domains converging on identical verdict, subtype, and line citations without the answer leaking between passes is a strong signal the audit method is sound.

- **High confidence:** all WIRED and PARTIAL verdicts that cite a specific shader line + call-order (the bulk). The combiner-order reasoning is verifiable and consistent.
- **Reconciled disagreements (5):** carbon×lava, machine×craters, magma×edifices, glacial×mountains, frost×craters. In every case the second auditor found a preset-gating fact or a wrong-signed/partial read the first missed; verdicts moved toward the stricter, more evidence-specific call. carbon×lava is the one I'd most want a live preset check on (relief said WIRED on the global albedo mask; exotic said ABSENT because lava never fires on the carbon preset — both are technically true of different conditions).
- **Lower confidence / can't fully resolve from code alone:** resolution-capped "runs but doesn't show" edges (gorge depth, dune orientation) — whether they read at intended framing distances is a visual UAT question, not a code question. Flagged as view-dependent-LOD rather than asserted as working.
