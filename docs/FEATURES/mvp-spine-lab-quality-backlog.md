## How the two statuses were determined

| | Meaning | Bar |
|---|---|---|
| **labStatus BUILT** | the quality issue is **RESOLVED** in the lab | a rework landed **and** Max UAT-passed it, or the mechanism he named was demonstrably replaced |
| **labStatus PARTIAL** | substantive work landed, complaint not closed | half the ask, or work that improved it incidentally without ever being scoped against his words |
| **labStatus UNBUILT** | still an open complaint | same mechanism/parameters he objected to; no workstream scoped against it |
| **labStatus UNKNOWN** | evidence points both ways | named below with what would settle it |
| **gameStatus** | **can the game even exhibit this issue yet?** | WIRED = the lab mechanism reaches the game through the world engine · PARTIAL = partially · **ABSENT** = the game has no such feature, *or* has its own unrelated parallel implementation slated for replacement — so the issue cannot appear there |

**ABSENT is the common and correct answer** on this spine. These are complaints about *lab*
renderer quality, and 12 of the 14 mechanisms Max objected to have zero presence in
`src/objects/Planet.js`. A `[lab]` tag was added to
[`planet-visual-features.md`](planet-visual-features.md)'s legend on 2026-08-06 for exactly this
reason — the old legend could not express "built in the lab, absent from the game." BUILT/ABSENT
here expresses the same distinction.

⚠ **Two entries are the codebase's signature failure mode** — a measurement that is entirely true
and entirely misleading. They are flagged inline: **QB-1** (the lab shows no orange belt, which is
correct *and* means the feature Max asked for does not exist) and **QB-3** (F11 measures `.00014`
"inert" while measuring a path that is pinned to zero **on purpose**).
