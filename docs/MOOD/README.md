## How this index works

- **Annotated** entries have caption + "what it references" + cited-by
  links. These are the references actively used in design decisions.
- **Unannotated** entries are bootstrapped from filenames by
  `scripts/mood-index-bootstrap.sh`; pure inventory until referenced.
  Promote to Annotated when cited from a feature or system doc.

**Refresh inventory:** `npm run mood-bootstrap`
(idempotent — only touches content between AUTO-INVENTORY markers).

**Promotion rot check:** `doc-rot-check.sh` flags any image filename
cited from `FEATURES/*.md` or `SYSTEMS/*/*.md` that still appears in
the Unannotated block.
